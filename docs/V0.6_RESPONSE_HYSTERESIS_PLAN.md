# V0.6 — Response Time & Hysteresis Analysis Plan

## Scope

Add two new engineering analysis modes to **Damper Test Data Analyzer** without changing the existing center-stroke damping-force workflow:

1. **Response Time / Switching Time**
2. **Hysteresis**

Each mode shall support OEM-specific evaluation profiles instead of hard-coding one generic rule.

---

## 1. Source rules captured from the supplied specifications

### Audi VR-EF-33-2 — Switching time

Source: supplied `AUDI.pdf`, section 18.

- Triangle displacement excitation, stroke parameter `s = 50 mm`.
- Test speeds: `0.052 / 0.131 / 0.262 / 0.524 m/s`.
- Three measured cycles per condition.
- Current switches between soft and hard during one rebound/compression movement in sequence `soft → hard → soft`.
- Current switching instant must be selected while test speed is constant and actual current equals commanded current.
- Sampling rate at least `4 kHz`; if anti-aliasing is used its -3 dB cut-off shall be greater than `2 kHz`.
- Valve current is measured through a shunt and filtered only during post-processing.
- Evaluate four transition types: rebound force build-up, rebound force decay, compression force build-up, compression force decay.
- `t0`: time at which valve current reaches 10% of the commanded current step.
- `F_I=10% = F(t0)`.
- `F100%`: mean of force values in the final 2% of the step.
- `ΔF_total = F100% - F_I=10%`.
- Determine force thresholds at `1%`, `63%`, `90%` of the force step.
- Report dead time `Δt1%`, switching time `Δt63%`, switching time `Δt90%`, force gradients at 63% and 90%.
- Limits are project-specific; software shall not invent pass/fail limits.

### Audi VR-EF-33-2 — Switching hysteresis

Source: supplied `AUDI.pdf`, section 19.

- Room/test-start temperature: `20 ± 2 °C`.
- Sampling rate at least `1 kHz`; anti-alias -3 dB cut-off greater than `500 Hz` if used.
- Speed overshoot/undershoot max. `10%` of target speed.
- Test frequency `1.31 Hz` with:
  - `s = 9.92 mm`, `v = 0.052 m/s`
  - `s = 25 mm`, `v = 0.131 m/s`
  - `s = 50 mm`, `v = 0.262 m/s`
- Seven cycles per current state.
- Current states: soft / characteristic-map-center current (KFM) / hard.
- Required switching sequences include `hard → KFM → soft → KFM → hard → KFM → soft` and the inverse comparison path.
- Before evaluation, smooth measured damping force by moving average using ±3% of the number of samples per stroke.
- Hysteresis is evaluated at KFM for rebound and compression.
- Mean force before and after switching is based on at least four cycles; first cycle after switching is excluded from the mean.
- Report absolute hysteresis in N and relative hysteresis in %, relative to the spread `Fmax - Fmin` at the respective test speed.
- Also report the first-cycle force difference separately for the required motion direction.
- Limits are project-specific.

### BMW 11738444-000-03 — Hysteresis measurement (VDC dampers)

Source: supplied `BWM.pdf`, section 2.4.7.

- Triangle displacement at constant velocity.
- Current step occurs at the damper stroke reversal point.
- Measure increasing and decreasing current sweeps.
- Stroke: `±50 mm`.
- Speeds: `0.050 / 0.131 / 0.262 / 0.524 / 1.048 m/s`.
- Current increment: `+0.2 A`; current decrement: `-0.2 A`.
- Pair increasing/decreasing damping-force results at the same current and direction.
- Normalize force to damping magnitude using motion direction before percentage comparison.
- Reference value is the mean of the two increasing/decreasing damping-force values.
- Hysteresis percentage = absolute increasing/decreasing force difference divided by their mean reference value × 100.
- Maximum permissible percentage comes from the project requirements; software shall expose an optional limit input but no built-in limit.

### BMW 11738444-000-03 — Response to setpoint changes

Source: supplied `BWM.pdf`, section 2.4.9.

- Trapezoidal displacement at constant speed.
- Current step occurs at zero crossing of damper displacement.
- Stroke: `±50 mm`.
- Speeds: `0.0131 / 0.524 / 1.048 m/s`.
- Current step types: soft→hard, soft→medium, hard→medium, hard→soft.
- Evaluate `t63%` and `t90%` from the force response.
- Pass/fail criterion is the project-specific `t90%` requirement.
- The supplied BMW excerpt does not explicitly define the measured-current trigger fraction; the software will therefore expose the trigger fraction as a visible setting. Default is 10% for compatibility with the supplied reference plot and the Audi definition, but it is not labelled as a BMW normative value.

## 2. Raw-data handling

### MTS Data Acquisition format

Fix the existing parser so that channel values are assigned by the actual header column positions. MTS exports may reorder:

- Running Time
- Axial Displacement
- Axial Load
- Current feedback

The parser must not assume a fixed column order.

### Headerless high-speed response DAT

Support numeric high-speed response exports where the first four numeric channels can be inferred. For the supplied sample the inferred mapping is:

1. time [s]
2. load [N]
3. current [A]
4. displacement [mm]

Extra worksheet/manual-calculation columns on the right shall be ignored.

Channel inference must report its mapping and confidence; strict mode can require manual confirmation in a later UI iteration.

---

## 3. Response-time processing pipeline

`Import → channel mapping → sample-rate check → current start/end plateaus → measured-current trigger → F(t0) → final force → 1/63/90% force thresholds → interpolated crossing times → gradients → synchronized plots → result table/export`

### Core outputs

- OEM profile
- current start/end
- current step
- trigger current and `t0`
- displacement and velocity at `t0`
- motion direction
- `F0`, `F100`, `ΔF`
- `t1%`, `t63%`, `t90%` [ms]
- dead time [ms]
- gradient 63% / 90% [N/s]
- sample rate [Hz]
- warnings/status

### Plot design

Use the supplied reference image as the visual target:

1. Current vs time with I0 / I10 / I100 and trigger line.
2. Force vs time with F0 / F63 / F90 / F100 and crossing-time lines.
3. Velocity vs time.

All three plots share the same time axis.

---

## 4. BMW hysteresis processing pipeline

`Import → current-level/run recognition → motion direction → zero-displacement force interpolation → Up/Down pairing → directional force normalization → hysteresis N / % → F-I plots → table/export`

For compression, retain the signed engineering force in the table but normalize to positive damping magnitude for percentage calculation.

---

## 5. Audi hysteresis processing pipeline

`Import → current plateau/state recognition → cycle/reversal detection → samples-per-stroke → ±3% moving-average force smoothing → identify KFM plateau groups → exclude first cycle after each switch → mean at least 4 cycles → before/after comparison → absolute/relative hysteresis → first-cycle delta`

Strict Audi reporting requires mapping actual current levels to `soft / KFM / hard`; the UI shall expose this mapping rather than assuming whether high current means soft or hard.

---

## 6. UI architecture

Keep existing damping-force analysis unchanged and add two independent workspace pages:

- **响应时间 / Response Time**
- **迟滞 / Hysteresis**

Each page gets its own file selector, OEM profile selector, analysis settings, synchronized engineering plot(s), result table, warning/status area and Excel export.

Default UI language remains Chinese.

---

## 7. Validation strategy

### Supplied response DAT

- inferred channels: time / load / current / displacement
- expected sample rate approximately 4096 Hz
- one dominant current step from high current to low current
- use it to validate current-trigger detection, interpolation and response plots
- do not force the software to reproduce manual side calculations if those calculations use extrema rather than the OEM `F100` definition

### Supplied hysteresis DAT

- MTS repeated Data Acquisition blocks
- current sequence approximately `0.3 → 0.5 → ... → 1.7 → ... → 0.3 A`
- measured mid-stroke speed approximately `1.05 m/s`, matching the BMW 1.048 m/s test point
- use it to validate header-order parsing and Up/Down hysteresis pairing

### Regression tests

Add synthetic tests for:

- reordered MTS columns
- headerless response channel inference
- response t1/t63/t90 crossing interpolation
- falling and rising force transitions
- BMW hysteresis percentage formula for rebound and compression
- optional limit / no invented limit
- GUI page presence and Chinese default labels
