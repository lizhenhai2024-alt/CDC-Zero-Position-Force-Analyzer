# V0.8.4 Response Marker Layout

## Scope

V0.8.4 changes only response-plot presentation and traceability. It does not change response-event detection, force-threshold calculations, the I₁₀% timing basis, target-speed matching, BMW/Audi profile logic, or gas-force correction.

## Annotation style

The Current-Time and Force-Time plots use the same annotation rule:

- transparent text background;
- normal font weight;
- annotation font size matches the corresponding Y-axis title font;
- engineering subscripts remain unchanged (`I₁₀%`, `I₁₀₀%`, `F₁%`, `F₆₃%`, `F₉₀%`, `F₁₀₀%`, `t₀`, `t₁%`, `t₆₃%`, `t₉₀%`).

Horizontal threshold labels remain immediately above their horizontal reference line.

## Vertical-reference intersections

Every vertical dashed reference line on the Current-Time and Force-Time plots has a circular marker at its intersection with the measured curve.

The marker ordinate is calculated by linear interpolation of the displayed measured data at the exact vertical-reference timestamp. It is not placed from a nominal threshold value or a nearest-sample approximation.

Current-Time:

- `t₀` / I₁₀% crossing.

Force-Time:

- `t₀`;
- `t₁%`;
- `t₆₃%`;
- `t₉₀%`.

## Vertical text placement

Text associated with a vertical reference line uses exactly the same X coordinate as the curve-intersection marker. The text is displaced only vertically, above or below the intersection, so the visual relationship is unambiguous.

Placement automatically chooses above/below to avoid the plot boundary and alternates where practical to reduce overlap. Horizontal offset from the reference line is not used.

## Preserved V0.8.3 engineering rules

- `t₁%`, `t₆₃%`, `t₉₀%` remain calculated as force-threshold crossing timestamp minus I₁₀% current-crossing timestamp.
- BMW/Audi profile selection remains independent from user-defined positive finite target speeds.
- The displayed force interval still covers the F₁₀₀% endpoint window.
- Gas rebound-force correction retains both add and subtract operations.
- `t₉₀%限值` remains optional; no pass/fail judgment is made when no limit is configured.

## Automated acceptance

V0.8.4 tests verify:

1. transparent annotation backgrounds;
2. normal font weight;
3. annotation font metrics equal to the axis-title font metrics;
4. current `t₀` marker lies on the interpolated measured-current curve;
5. force `t₀`, `t₁%`, `t₆₃%`, `t₉₀%` markers lie on the interpolated measured-force curve;
6. vertical-reference text X coordinates equal their marker/reference-line X coordinates;
7. V0.8.4 is the packaged GUI entry point.
