# V0.6 Real-data validation

This note records engineering validation performed with the two user-supplied DAT files. The raw customer files themselves are **not** committed to the repository.

## 1. Response-time DAT

### Channel inference

The file is a headerless four-channel export. The corrected inference identifies:

1. Time
2. Axial load
3. Valve current feedback
4. Axial displacement

The inferred sampling frequency is approximately **4096 Hz**. The displacement slope around the switching event corresponds to approximately **1.048 m/s** rebound motion.

### Current implementation result

Using the current engineering endpoint setting (10% measured-current trigger and 2% tail mean for the force endpoint), the real record gives approximately:

- current start: 1.620 A
- current end: 0.274 A
- direction: Rebound
- t0: 0.277715 s
- dead time t1: 0.99 ms
- t63: 5.45 ms
- t90: 7.21 ms
- sample rate: 4096.01 Hz

### Important BMW validation item

The supplied BMW excerpt defines the trapezoidal constant-speed response test and evaluates t90, but the supplied pages do **not** explicitly define the numerical extraction rule for `F Anfang` and `F Ende`.

The raw DAT also contains manual worksheet annotations indicating approximately:

- initial force: 7252.236 N
- end force: 3767.269 N
- force delta: 3484.967 N
- 90% delta: 3136.470 N
- F90 target: 4115.766 N
- manually marked time difference: 7.8125 ms

This differs from the current generic tail-mean endpoint result because the record has a force undershoot and then rises again. Therefore **7.21 ms must not yet be treated as the final BMW normative value**. The BMW endpoint extraction method remains an explicit validation item. Audi's endpoint rule is not to be silently applied to BMW.

## 2. Hysteresis DAT

The second DAT is an MTS file with reordered channels:

- Running Time
- Current feedback
- Axial Displacement
- Axial Load

The parser now resolves channels by header names instead of fixed column position.

The file contains 15 acquisition blocks with a current sweep approximately:

`0.3 -> 0.5 -> 0.7 -> 0.9 -> 1.1 -> 1.3 -> 1.5 -> 1.7 -> 1.5 -> 1.3 -> 1.1 -> 0.9 -> 0.7 -> 0.5 -> 0.3 A`

Most blocks are sampled at approximately 204.8 Hz and the center-stroke speed is approximately 1.05 m/s. This pattern is consistent with the BMW increasing/decreasing-current hysteresis processing route rather than the Audi Soft/KFM/Hard seven-cycle route.

## 3. Regression status

The two previously failing automated cases have been corrected:

- headerless response channel inference no longer confuses a monotonic displacement ramp with the time channel;
- force-threshold search starts from the exact interpolated t0 point, so the 1% dead-time crossing is retained.

The synthetic OEM processing regression suite covers:

- reordered MTS headers;
- headerless dynamic channel inference;
- response t1/t63/t90 interpolation;
- BMW increasing/decreasing-current hysteresis pairing;
- Audi first-cycle exclusion, minimum retained-cycle logic and KFM hysteresis calculation.
