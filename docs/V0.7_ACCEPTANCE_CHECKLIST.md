# V0.7 Engineering Acceptance Checklist

Use a complete BMW/Audi response-time raw data file for final acceptance.

## Response full-file recognition

- [ ] File opens without manual channel remapping
- [ ] All intended current-step events are found
- [ ] BMW typical file: Soft->Hard, Soft->Medium, Hard->Medium, Hard->Soft
- [ ] Each stage has one Rebound (+) and one Compression (-) result where present in the raw procedure
- [ ] No extra false event is created by current ripple/noise
- [ ] Event selector and result-table row select the same plotted event

## Event detail plot

- [ ] Current trace is clearly visible and thick enough
- [ ] I10% and I100% are labeled
- [ ] Damping-force trace shows Rebound (+) or Compression (-)
- [ ] F1%, F10%, F63%, F90%, F100% are labeled
- [ ] Intersection points are visible at evaluated force/time crossings
- [ ] All reference/marker lines are dashed
- [ ] Target velocity is shown as a horizontal dashed line
- [ ] Plot height is sufficient for engineering review

## Full overview

- [ ] Full overview shows Force / Current / Displacement over the full test sequence
- [ ] Detected switching events are shown as vertical dashed lines
- [ ] Stage/direction labels are readable
- [ ] Overview can be exported as PNG

## Hysteresis

- [ ] Audi Soft/KFM/Hard processing remains unchanged
- [ ] Hysteresis plot can be exported as PNG
