# V0.7.4 Target-speed Response Evaluation

## Problem fixed

The response page previously accepted a detected current step even when the step was outside the OEM target-speed region. Long event windows also made the three plots visually dense, with horizontal grid/marker lines obscuring the actual response.

## Evaluation rule

V0.7.4 first detects all current transitions in the complete file and then evaluates a transition only when the measured switching speed is within the engineering target-speed window.

- BMW nominal speed magnitudes: 0.0131 / 0.524 / 1.048 m/s.
- Audi nominal speed magnitudes: 0.052 / 0.131 / 0.262 / 0.524 m/s.
- Engineering target-speed selection tolerance: ±10%; a 0.002 m/s absolute floor is used for the very-low-speed BMW point.
- The continuous target-speed component containing t0 defines the force-response evaluation region.
- F100 and the 1% / 63% / 90% force thresholds are calculated only inside that target-speed region.
- Current steps outside the target-speed region are counted and excluded from the response result.
- Direction is defined from load sign: positive = Rebound, negative = Compression. Velocity sign is used only for target-speed sign/QA.

For BMW, F100 is still an engineering endpoint taken inside the continuous target-speed window. The exact project/normative `F Anfang / F Ende` extraction rule remains an open controlled-specification item.

## Plot changes

- response event display is limited to the local target-speed window;
- horizontal plot grid lines are disabled; only a light X grid remains;
- main current / force / velocity curves are thicker;
- all reference lines are dashed;
- current: only 10% and 100% horizontal references;
- force: only 1% / 63% / 90% / 100% horizontal references plus t0/t1/t63/t90 vertical references;
- velocity: signed target velocity horizontal reference;
- force plot identifies `Rebound (+)` or `Compression (-)`;
- table text/row height and event selector are enlarged.

## Regression coverage

The V0.7.4 synthetic tests include:

1. three current steps at 0.524 m/s, 0.35 m/s and -1.048 m/s, proving that the 0.35 m/s off-target step is rejected;
2. a complete BMW sequence with four transitions × rebound/compression. Eight target-speed response events are retained while seven reset-current transitions outside the target-speed windows are rejected.
