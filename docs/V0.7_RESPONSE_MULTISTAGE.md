# V0.7 Response Multi-stage and Plot Upgrade

## Scope

V0.7 upgrades the response-time module from a single-window analyzer to a full-file current-step workflow and upgrades the plots toward the supplied Audi Figure 15 / Figure 16 presentation style.

## Full-file response processing

For each valid current-step event the software records:

- Event ID and Block ID
- current start / end / delta
- stage label (Soft / Medium / Hard when three force levels can be inferred)
- Rebound / Compression direction using load sign, with velocity-direction consistency check
- measured and snapped target velocity
- I10% trigger and t0
- F0, F1%, F10%, F63%, F90%, F100%
- t1%, t10%, t63%, t90 and force gradients
- start/end evaluation window locations
- status / data-quality issues

BMW target-speed recognition uses 0.0131 / 0.524 / 1.048 m/s. Audi target-speed recognition uses 0.052 / 0.131 / 0.262 / 0.524 m/s.

## BMW workflow regression

A synthetic 4096 Hz full-file regression covers eight response events:

1. Soft -> Hard / Rebound
2. Soft -> Hard / Compression
3. Soft -> Medium / Rebound
4. Soft -> Medium / Compression
5. Hard -> Medium / Rebound
6. Hard -> Medium / Compression
7. Hard -> Soft / Rebound
8. Hard -> Soft / Compression

This regression verifies all eight events, the four stage names, both force signs, F10%, t10%, t63%, t90 and 0.524 m/s target-speed recognition.

## Response plots

### Event detail (Audi Figure 16 style)

- thicker signal curves and larger labels
- all evaluation marker lines use dashed lines
- current plot: I10% and I100%, t0 and current intersection
- force plot: Rebound (+) / Compression (-), F0, F1%, F10%, F63%, F90%, F100%, t0 / t1 / t10 / t63 / t90 and intersection markers
- Audi profile: start/end reference regions are displayed
- velocity plot: target-speed horizontal dashed line
- taller plot area

### Full overview (Audi Figure 15 style)

The response page includes a switchable full-test overview showing synchronized:

- damping force vs time
- valve current vs time
- displacement vs time

Detected switching events are marked with dashed vertical lines and event/stage labels.

## UI and export

- response-time and hysteresis plots can both be exported to PNG
- Chinese UI uses Chinese table headers
- `专业帮助` is renamed to `帮助`
- duplicated top `帮助 / 使用说明` button is hidden
- `界面语言` is renamed to `语言` and the selector is placed at the right side of the top toolbar

## Validation boundary

The supplied headerless response DAT currently available in the conversation is a short single-transition excerpt (approximately 30 ms), not an eight-stage full-flow response record. Therefore real-data validation confirms the single response transition and channel inference, while the complete eight-event workflow is currently covered by automated synthetic regression. A complete BMW/Audi response-flow DAT should be used for final real-data stage-count validation before controlled customer reporting.
