# CDC Zero Position Force Analyzer — V1.0 Requirements

## 1. Scope

A standalone Windows test-data processing application for CDC damper bench data.

Primary workflow:

`Import data -> recognize current conditions -> identify rebound/compression and cycles -> evaluate center-stroke force -> optional gas-force correction -> visualize -> export Excel`

## 2. Input data

Primary supported fields:

- `Running Time` [s]
- `Axial Displacement` [mm]
- `Axial Load` [N]
- `CDC 1 Current FB_1` [A]

Initial formats:

- MTS `.dat`
- `.csv`
- `.xlsx`

For MTS DAT files the parser shall support repeated `Data Acquisition` blocks, repeated headers and unit rows. Data blocks and cycles are different concepts.

## 3. Internal data model

Raw fields shall never be overwritten.

Derived fields may include:

- `Block ID`
- `Run ID`
- `Cycle ID`
- `Current Actual`
- `Current Label`
- `Sweep Direction`
- `Motion Direction`
- `Gas Force`
- `Corrected Axial Load`
- `Valid`
- quality/status flags

## 4. Current recognition

- Automatically detect stable current platforms from `CDC 1 Current FB_1`.
- Representative current: median of stable segment.
- Display/group label: round to 1 decimal place.
- Same current may occur in multiple Runs.
- Automatically label rising/falling current sweeps where possible.
- Preserve actual current statistics for diagnostics.

## 5. Direction convention

Default:

- `dX/dt > 0` -> Rebound
- `dX/dt < 0` -> Compression
- Rebound load shall normally be `> 0`
- Compression load shall normally be `< 0`

Motion direction is determined from displacement derivative; force sign is used as a consistency check.

Provide independent user controls for displacement-direction reversal and load-sign reversal.

## 6. Cycle recognition

- Detect complete cycles from displacement extrema / directional zero crossings.
- Do not assume one Data Acquisition block equals one cycle.
- Partial cycles shall be identified and excluded from customer-evaluation calculations by default.
- Customer rules may select the last complete measured cycle.

## 7. Center position

For a selected complete cycle:

`X_center = (X_max + X_min) / 2`

`Total Stroke = X_max - X_min`

Do not assume the measured center is exactly 0 mm.

## 8. Force evaluation profiles

### 8.1 Audi Profile

Customer requirement captured for V1.0:

- Use the **last complete measured cycle**.
- Determine force inside an evaluation window around the stroke center.
- Evaluation-window **total width = 10% of total stroke**.
- Therefore window limits are:

`X_center ± 5% * Total Stroke`

Within the window:

- Rebound force result = maximum positive force in the rebound-direction data.
- Compression force result = minimum negative force in the compression-direction data.

The program shall display the calculated center, total stroke and actual window limits.

### 8.2 Window Mean Profile

Engineering-analysis profile:

- Evaluate rebound and compression separately within a configurable center window.
- Statistic = arithmetic mean by default.
- Window percentage shall be user configurable.
- UI must explicitly state the percentage basis (single-sided amplitude or total stroke) to avoid ambiguity.
- Suggested presets: 2%, 5%, 10%, Custom.

### 8.3 Zero Crossing Profile

- Target displacement default = 0.000 mm.
- Calculate rebound and compression force using adjacent-point linear interpolation at the target displacement.
- Keep as an independent evaluation/diagnostic method.

### 8.4 Comparison / diagnostics

Where useful, the analyzer may calculate multiple methods in parallel and report their difference for quality checking, without changing the selected customer result.

## 9. Gas rebound-force correction

Modes:

1. Off
2. Direct input of center-position gas force `Fg` [N]
3. Calculate center-position gas force from gas gauge pressure and piston-rod diameter

For constant-force correction:

`Corrected Axial Load = Axial Load - Fg`

Raw `Axial Load` shall always be retained unchanged.

Evaluation may be performed on either measured or corrected force according to user selection.

A future variable gas model may use pressure-volume behavior, but it is outside the minimum V1.0 requirement.

## 10. Plotting

X and Y fields shall be user selectable.

Selectable channels should include at least:

- Running Time
- Axial Displacement
- Axial Load
- CDC 1 Current FB_1
- Corrected Axial Load
- Gas Force

Requirements:

- Single-field XY plotting
- Multiple Y channels
- Same-unit channels may overlay
- Different-unit channels should default to vertically stacked plots sharing the X axis
- Current / Run / Cycle filtering
- Raw / corrected selection
- Zoom, pan, reset and cursor/data tooltip
- Export chart as PNG
- For force-displacement plots, show evaluation window and selected rebound/compression result points
- For Audi mode, clearly mark `Last Complete Cycle` and the 10%-stroke evaluation region

## 11. Results

### Summary level

At minimum:

- Current label [A]
- Rebound result [N]
- Compression result [N]
- Run count
- Evaluation profile
- Status

### Run level

At minimum:

- Current label
- Run ID
- actual current statistics
- sweep direction
- rebound result
- compression result
- status

### Cycle level

At minimum:

- Current
- Run
- Cycle
- completeness
- center position
- total stroke
- evaluation-window limits
- rebound result
- compression result

## 12. Quality checks

Flag at least:

- no valid center crossing / center window data
- incomplete cycle
- rebound result with unexpected negative sign
- compression result with unexpected positive sign
- unstable current
- non-monotonic/invalid time data
- displacement jumps
- insufficient points in an evaluation window
- excessive repeatability difference between Runs

Status values:

- OK
- Warning
- Invalid

## 13. Excel export

Default format: `.xlsx`.

Suggested sheets:

- `Summary`
- `Run Detail`
- `Cycle Detail`
- `Settings`

Optional raw-data export may be added. Legacy `.xls` support is optional and shall not limit the core application.

## 14. Suggested desktop stack

- Python
- PySide6
- NumPy
- Pandas
- PyQtGraph
- openpyxl
- PyInstaller
